# BO Checklist Dashboard — bookmarklet build

Живой «Data to check»-дашборд **без сервера и без расширений**. Работает внутри открытой
страницы lfscbo.com, использует твою собственную BO-сессию.

## Как поставить (один раз)

1. Открой страницу проекта на GitHub Pages и нажми **Copy bookmarklet code**.
2. В браузере: ПКМ по панели закладок → «Добавить страницу...» → имя `BO Checklist`,
   в поле URL вставь скопированный код. (Или просто перетащи кнопку **drag me** с
   страницы на панель закладок.)
3. Открой lfscbo.com, залогинься в BO как обычно → кликни закладку `BO Checklist`.
   Появится панель и начнётся первый скан всех клиентов (~2–4 минуты).

## Обновления

- Код обновляется коммитом в репозиторий: GitHub Pages пересобирается ~1.5 мин,
  после этого следующий клик по закладке тянет свежую версию.
- Локальная серверная версия (`a/work/bo-dashboard-server.mjs`) не изменена и
  продолжает работать параллельно.
## Что внутри

- Скан всех клиентов: `core/userTeamSelect` → `lfs/toCheck/index`, разбор вкладок
  (тот же парсер, что и в серверной версии, включая «coffee»-бейджи и late tabs
  для Mac88 / Royal Gaming).
- Счётчик Ticketing requests (парсер из `ticketing-requests.mjs`).
- Автообновление каждые 5 минут, пока вкладка открыта.
- Ручные кнопки: Scan / Hide night tabs / Hide / Close.
- Активный клиент BO после скана возвращается к исходному.

## Сборка

```cmd
node tools\build-bookmarklet.mjs v1
```

- `docs/bo-checklist.bookmarklet.txt` — сам bookmarklet (одной строкой).
- `docs/index.html` — страница для GitHub Pages с инструкцией и кнопкой копирования
  (Pages подключён к ветке `main`, папка `/docs`).
- При желании: `set PAGES_URL=https://.../bo-dashboard.js && node tools\build-bookmarklet.mjs`
  — дополнительно соберёт тонкий загрузчик `docs/bo-checklist.loader.txt`.

## Важно

- Панель живёт только пока открыта вкладка lfscbo.com.
- Не пробрасывай ничего в интернет: всё работает только внутри BO-сессии текущего браузера.
